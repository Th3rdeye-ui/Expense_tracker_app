# 💰 Expense Tracker App (Python)

## 📌 About the Project
The **Expense Tracker App** is a simple, menu-driven Python application that helps users manage and track their daily expenses. Users can add expenses, view all recorded expenses, and calculate their total spending.

This project is developed using Python fundamentals, including lists, dictionaries, loops, conditional statements, functions, and exception handling.

## ✨ Features

- **Add Expenses:** Record expenses with date, category, description, and amount.
- **View Expenses:** Display all recorded expenses in an organized format.
- **Calculate Total Expenses:** Automatically calculate the total amount spent.
- **Input Validation:** Handle invalid amount inputs using exception handling.
- **Interactive Menu:** Simple menu-driven interface for easy navigation.
- **Exit Option:** Safely exit the application.

## 🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- While Loops
- Conditional Statements
- For Loops
- Exception Handling (`try-except`)
- Built-in Functions (`sum()`, `enumerate()`)

## 💡 How It Works

1. Select option 1 to add a new expense.
2. Enter the date, category, description, and amount.
3. Select option 2 to view all recorded expenses.
4. Select option 3 to calculate your total expenses.
5. Select option 4 to exit the application.
